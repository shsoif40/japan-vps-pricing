## 常见问题

**日本服务器最便宜能到多少？**
普通线路的入门云主机可以做到 $17–$30/月区间，中国大陆优化线路的 VPS 起步价通常在 $29 上下，物理独服按配置从几百到几千元人民币每月不等，多 IP 站群机型会更贵。

**三网优化线路的溢价花在哪？**
花在回程。普通国际中转从中国电信骨干访问东京，RTT 常见 150–300ms，晚高峰还会退化；三网精品回程可以做到中国大陆主要城市 50ms 以内，东京到华东在 30–50ms。

**$49 的 Mini 和 $89 的 Air 怎么选？**
看瓶颈在哪。Mini 端口 1.5 Gbps、1 TB 流量，适合带宽敏感但内存需求不大的场景；Air 给到 4 核 8 GB 和 2 TB 流量，但端口退回 1 Gbps，适合跑 WooCommerce 这类吃内存的应用。

**流量超了会怎样？**
限速到 20 KB/s，直到下个计费周期重置，不停机但基本不可用，所以按实际用量留出余量比事后补救划算。

**能装 Windows 吗？**
Pro 和 Ultra 支持，Nano、Mini、Air 只能跑 Linux。
